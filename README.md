# Are you a Manhattan Institute Urbanist?

These 50 ideas are compiled from MI scholars and research: the 50 recommendations from the Manhattan Institute issue brief [“A Better Everyday Life in New York: 50 Practical Ideas to Renew NYC’s Promise of Opportunity”](https://manhattan.institute/article/a-better-everyday-life-in-new-york-50-practical-ideas-to-renew-nycs-promise-of-opportunity) (John Ketcham and Sean Speer, Oct. 20, 2026) as a swipe deck.

Like, pass, or super-like each idea. The swipe report scores agreement with MI (every card is one of the brief’s recommendations, so a like or super-like counts as agreement), breaks it down by area, and redraws an illustrated New York block with only the ideas you liked built on it.

The report card is drawn on a canvas, so a screenshot matches the saved image. Readers can save it as a post (4:5) or story (9:16), share it natively on phones, copy an emoji summary, or copy a link that reopens their report for friends (all 50 verdicts fit in a 17-character code in the URL hash). No backend; swipes stay in the reader’s browser.

Card text is condensed from the brief. Companion to the [interactive edition](https://danielgolliher.github.io/better-everyday-life/). Single self-contained `index.html`; no build step.
